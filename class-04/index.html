Last week's homework folders

  • The agent worked in a folder of your own files
  • Some of you had files changed or deleted
  • There was no earlier copy to go back to

One request, many changed files

  • An agent can change many files in one step
  • Codex has no undo command
  • OpenAI says to save a version before and after each task

Saved versions of a file and of a project

essay.docx

essay-v2.docx

  • Most of us have saved essays this way
  • Git does it for the whole project folder
  • Each saved version is a commit
  • Each commit has a short message about what changed

Commits and branches

  • A branch is a separate line of work
  • It starts from a commit
  • Codex sometimes makes one on its own when it starts a task

Codex and project history

  • In a folder with no history, Codex suggests read-only mode, so it can look at files but not edit them
  • In the review pane, you can see what changed in each file and put a file back
  • You need history to use the review pane, and Codex offers to set it up
  • Codex asks for approval before saving a version

Files a save covers

  • Changes since the last commit are not saved yet

Commit messages and new conversations

  • A new conversation remembers nothing from the last one
  • It can read the history
  • It learns what was done and why from the commit messages

Add a map of requests by borough

Git and GitHub

  • Git keeps the history in the project folder
  • If you delete the folder, the history goes too
  • GitHub is a website that keeps a copy

Going back to a saved version

  • The folder returns to that version
  • Later commits are still kept
  • After a bad run, some people go back and ask again

Finding the change that broke something

  • The agent goes back through the saved versions
  • It tests each one
  • The first version that fails has the change that broke it

Several tasks at once

  • The Codex app can run tasks at the same time
  • Each task gets its own copy and branch
  • The results are combined afterward
  • If two tasks change the same lines, someone has to choose
