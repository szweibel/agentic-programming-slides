The conversation does not fit forever

When the conversation gets long, the app replaces the early part with a summary, and details are lost. After that, the model no longer sees a decision made an hour earlier.

Start a new conversation for a new task. Between conversations, it remembers nothing except what is in the files.

How it acts

The model writes a request, and the program carries it out with a tool and sends the result back to the model, which writes the next step.

It can only do what it has a tool for

  • With a tool for writing files, the model can change a file on your computer
  • Without one, it can only describe the change for you to make
  • OpenAI decides which tools the app has, and you choose which ones need your approval
