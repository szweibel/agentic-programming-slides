NYC 311

The city's non-emergency service line

Noise, parking, heating, and similar complaints. Each report becomes a record, and the city publishes the records on NYC Open Data.

Each record holds

Complaint type · borough · date created · status · agency · location

We will ask for the most recent full week.

Source: NYC Open Data, "311 Service Requests from 2020 to Present," dataset erm2-nwe9.

Public, local, no privacy problem. The data comes in live tonight.

The prompt

Build a small web app for New Yorkers to explore the most recent full week of NYC 311 service requests from NYC Open Data. Let people compare complaint types and boroughs. Show where the data came from and which dates it covers. Start it so we can open it in a browser.

Type it live. Before enter, ask what the prompt does not say. Pause at the first permission request and at the first files. Open the folder. When it finishes, open the page and test it: boroughs, complaint types, phone width. Ask the room for one change, type it, run it, and repeat the test that failed.
