Skills

Contents of a skill folder

  • A skill is a folder of instructions for one kind of work
  • The main file is SKILL.md

The start of a SKILL.md file

  • It's all text
  • If you can write clear instructions for a person, you can write one

Skills during a conversation

  • Unused skills take up almost no room
  • You can also call one by name

A prompt, a skill, and project instructions

  • Project instructions come in Class 13

Sources of skills

Installing a skill from someone else

  • The agent follows the skill's instructions on your computer
  • It may run the skill's scripts
  • Read SKILL.md before installing one from a source you don't know

The frontend-design skill

  • Anthropic publishes it on GitHub
  • In it, Anthropic asks the agent to base the design and typefaces on the subject
  • Anthropic also asks it to avoid the layouts and colors most generated pages use

Install the frontend-design skill from github.com/anthropics/skills/tree/main/skills/frontend-design

Comments and styling on the page

First versions that look alike

  • Models lean toward the most common choices they've seen
  • Your name and work come from your material
  • The layout, colors, and headline come from those defaults
  • The frontend-design skill has instructions against them

References for a design

  • Drag screenshots into the message
  • Say what to take from each one
  • "The headings are big and narrow" is enough

Four words for design

  • "The hierarchy is flat"
  • "The grid falls apart at phone width"
