From the folder to the browser

DHUM / DATA 70600 · Class 5

Markup in an HTML file

  • An HTML file is text with a label around each part
  • Heading, paragraph, quotation, link
  • How each kind looks is in the stylesheet
  • Screen readers, search engines, and the agent read the labels

The file and the live page

  • The browser builds a live copy of the page in memory, called the DOM
  • Scripts change the live copy
  • The file stays the same, so a reload clears a filter

One page, many requests

  • A page usually takes dozens of requests
  • Some go to other companies' servers

The server and the visitor's computer

  • Everything after the files arrive happens on the visitor's computer
  • The server never sees which filter someone picked

A page from the disk and from a server

  • Browsers restrict pages opened straight from the disk
  • They usually can't load their own data
  • With a local server, the page acts as it will on the web

Static and dynamic sites

  • Many DH projects are static on purpose
  • They need little upkeep for years
  • GitHub Pages hosts static sites

Screenshots and page structure

  • The agent can take a screenshot
  • Or it can read the page's structure, from the markup
  • Ask it to check both

A local address and a public address

  • If someone else types localhost, they reach their own computer

Putting the site online

GitHub Pages

  • GitHub keeps a copy of the folder, called a repository
  • Pages sends those files to visitors
  • It only sends files, so it hosts static sites
  • Sending saved versions to GitHub is a push
  • You sign in to GitHub yourself

Making the site public

  • Anyone can open it, and Google and the Internet Archive can copy it
  • Everything in the folder is published, including drafts, notes, and old files
  • The repository is usually public, with every file and every saved version
  • Use only images and texts that are yours, permitted, or openly licensed

Homework

  • Make a GitHub account if you don't have one
  • Look through your site's folder for anything you wouldn't publish
  • Have the agent publish the site with GitHub Pages
