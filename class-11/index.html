A picture as a grid of pixels

the diffusion image

  • A person or a model has to find the bicycle again from the colors

Training on noised pictures

Diffusion
Noised pictureplus its caption
→
Model
→
Its guess at the noisecompared with the noise that was added
  • Researchers add random noise to a very large set of captioned pictures
  • They give the model a noised picture and its caption, and it guesses the noise
  • After enough rounds it can remove noise from pictures it has never seen

Ho, Jain, Abbeel, Denoising Diffusion Probabilistic Models (2020). Photograph: Newspaper Row, New York, about 1900, public domain, Wikimedia Commons.

Generating by removing noise

Diffusion
step 0 of 30
  • The model starts from random noise

Four runs of one prompt

Diffusion
  • One prompt, four runs, four starting noise patterns
  • You set the subject with the prompt
  • The framing and the details change with the starting noise
  • People usually run several and pick one
